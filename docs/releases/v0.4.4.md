# OpenHero68 v0.4.4

Custom Effects now uses Start Custom and Return to onboard. Running changes
sync automatically; reopening the editor joins the existing configuration and
live preview without restarting playback. Different local drafts remain
available through Restore draft.

- Preset updates keep one request in flight and one latest edit pending. Disk
  saves coalesce after 300 ms and complete when playback stops or the app exits.
  Revision checks protect against conflicting editors; old acknowledgements
  do not replace newer edits. API 6 and the preset schema remain unchanged.
- The Onboard tab only opens its editor. Use onboard lighting returns to the
  existing firmware effect immediately, including unchanged Rainbow. Saving
  onboard RGB returns before writing; saving AP/RT elsewhere keeps RGB running.
- Onboard and Custom Per-key Color share a painting toolbar directly below the
  keyboard preview: selected count, All/WASD/arrows, clear, color picker, editable
  HEX and Paint keys. Brush changes do not paint; black turns key LEDs off.
- Actuation controls use yellow for a uniform value and gray for mixed values.
  Empty selection still disables editing. RT split retains both sensitivities
  and hides the Advanced Key icon; single-value RT retains it and its tooltip.
- The sidebar animates width over 220 ms and text over 140 ms, preserving the
  current page and focus. Reduced motion disables these transitions.

Validation: 533 automated tests passed, web/service TypeScript and Windows builds
passed, signed core and all eight Windows package files verified. Browser checks
used an isolated simulated service for joining, Start/Stop, live painting, HEX,
onboard switching, RT overlays, AP and sidebar. The painting toolbar was checked
at 390 px width. No physical keyboard writes, driver install, new hardware
benchmark or extended stress test was performed for this release.

The signed core requires launcher **0.4.2 or newer**. The complete Windows ZIP
bundles launcher 0.4.4. ViGEmBus remains a separate driver installation. Upgrade
the background app to use automatic Custom session recovery.

Web and service source are included in GitHub. This release contains only the
Windows ZIP, its checksum and the signed core pair; no Cloudflare Pages ZIP or
Cloudflare deployment.
