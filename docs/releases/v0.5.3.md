# OpenHero68 service v0.5.3 / UI v0.9.56

- Add Ember, Starlight, Afterglow and Tempo Pulse (manual 40–200 BPM), with
  Ember, Ocean, Sakura and Synthwave palettes.
- Correct Ember height, Starlight density limits, Afterglow continuity on quick
  taps and repeated presses, and visible Tempo Pulse tails at high BPM.
- Include new gradient layers when selecting contrasting automatic colors.
- Add audio Beat Pulse (Rhythm mode 430), sensitivity and synchronization offset.
  Use sample-clock timestamps, source-specific event corrections and complete
  reset when capture restarts. Cancel pending predictions when beat lock is lost.
- Hide unused Pulse controls and prevent starting modes unsupported by an older
  installed service. Preserve existing Rhythm modes and saved settings.
- Include the adjustable Scan endpoint pause added since v0.5.2.1.

Install or update with `OpenHero68-Setup-Windows-x64.exe`. This release includes
the updated native helper; a legacy core-only update is insufficient. Existing
setup installations can use the signed full application update.

Validation: 584 JavaScript tests, web/service typechecks, MSVC Rhythm/Beat/Pulse
regressions, native helper compilation, and local browser controls. GitHub
Actions additionally builds the production web and complete Windows installer,
runs isolated installation/update/rollback smoke tests, and signs and verifies
the setup release before publishing.

Beat Pulse may detect a tempo different from the track BPM. Real Windows
loopback probes produced variable estimates; stable accuracy across real music
and physical keyboard latency have not been verified. Allow a few seconds for
beat lock. Negative offset advances predicted beats; detected hits cannot be
displayed before detection.

The `cloudflare-pages` Actions artifact contains `open-hero68-pages.zip` for
dashboard upload, including the region Worker. Publishing this GitHub release
does not deploy Cloudflare Pages.
