# OpenHero68 service v0.5.0

- Windows setup EXE with optional Desktop shortcut and Auto-start.
- Optional ViGEmBus driver installation is shown only if the driver is missing.
- One-click signed full application updates, automatic app restart and rollback.
- Updates never restart Windows; driver reboot requirements are reported only.
- Settings, presets and logs stay in their existing LocalAppData directory.
- Windows builds, installer smoke tests and tag releases run in GitHub Actions.

Portable users run the setup once to migrate. New installations ignore legacy
downloaded cores. Gamepad remains disabled when the app starts. Windows publisher
signing is not configured, so first-run SmartScreen prompts may still appear.
