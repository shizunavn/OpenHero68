# OpenHero68 service 0.4.6

Digital gamepad buttons now follow the assigned key's Actuation Point and Rapid
Trigger settings read from the active HERO68 firmware profile. Previously the
service treated the Hall diagnostic pressed flag as AP/RT output without verifying
that correspondence, so changing AP or RT could leave Xbox buttons unchanged.

The native helper evaluates Hall distance using AP, separate press/release RT
thresholds and enabled top/bottom deadzones. RT can reactivate below AP until the
stroke resets at the top. Digital Hall sampling is 200 Hz. Analog controls retain
their existing independent travel mapping.

Start and profile/binding changes read firmware settings. AP/RT/deadzone edits
through the service reload them once per completed transaction while preserving
the Xbox controller and firmware suppression backup. Missing or malformed settings
prevent output; stale samples and pause still neutralize and require resting keys.

Install the **complete Windows x64 0.4.6 ZIP**. A core-only update cannot replace
the native helper, and the signed update manifest requires launcher 0.4.6.

Validation covers distance sequences with deliberately contradictory diagnostic
pressed flags, split RT and reactivation below AP, deadzones, stale recovery,
complete readback, live settings edits and independent profiles. Physical switch
behavior remains limited by the 200 Hz Hall snapshots; thresholds traversed wholly
between snapshots cannot be reconstructed.
