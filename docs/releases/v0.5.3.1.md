# OpenHero68 service v0.5.3.1

- Fix quiet playback being missed by Beat Pulse. Smooth input normalization
  before spectral analysis keeps the original onset thresholds and noise checks.
- Fix Beat Pulse never locking tempo on 192 kHz endpoints. Limit analysis to
  48 kHz, preserving the sample timeline and resampling phase across packets.
- Fix the Audio meter displaying LED brightness rather than captured sound.
  Audio activity now checks both positive and negative sample peaks.

Install the complete Windows setup because the native HID/audio helper changed.
The existing web build can display the corrected Audio meter without redeployment.

Validation includes native Rhythm/Beat/Pulse suites, quiet (-50 dB) drum PCM
at 44.1, 48, 88.2, 96 and 192 kHz, digital silence/noise/pad/vibrato rejection,
and actual Windows loopback capture. A local loopback probe locked near 128 BPM
and rendered pulses; that does not establish ground-truth BPM for arbitrary
music or physical LED timing. Some tracks can still have ambiguous tempo.

Beat Pulse estimates tempo within 60–200 BPM. Synthetic fast-drum probes at
240–600 BPM still rendered pulses, but locked to slower subdivisions; at
1000 BPM the probe did not lock. Full-speed speedcore synchronization is not
supported by this release. These probes are not tests of actual speedcore tracks.
