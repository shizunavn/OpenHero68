# OpenHero68 Gamepad and RGB Service v0.4.0

Adds analog Xbox gamepad output on Windows x64 through the separately installed
official ViGEmBus 1.22.0 driver. Setup & Remap, Configuration and Gamepad Tester
support per-key stick/trigger/button bindings, response curves, travel deadzones,
Snappy, circle/square output, angle adjustment, profile import/export and XInput
verification. Start/Stop is also available in the tray. Gamepad starts disabled
and continues running when the browser closes after it is enabled.

Gamepad, Custom Effects, Hall Stream and settings feedback now share one native
Hall scheduler. It polls only active source keys, batches at most nine due keys,
and reads common keys once at their highest requested rate. Gamepad analog requests
up to 200 Hz; RGB Hall demand stays 100 Hz. Existing RGB rendering and LED export
remain at their 60 FPS target. No 60 Hz Hall reduction policy is used.

An independent 50 ms watchdog neutralizes stale input. Configuration/profile
changes, pauses and failures clear arming; valid samples with all assigned keys
released are required before output resumes. Ordinary keyboard input stays
enabled. Keyboard suppression, DirectInput, mouse-to-stick and multiple keyboards
or virtual controllers are outside v1.

**Upgrade with the complete Windows ZIP:** this release requires core 0.4.0,
launcher 0.4.0 and API 6. Quit the old tray app, extract all files together to its
permanent folder, then run `Hero68RgbService.exe`. A core-only update cannot
upgrade older native launchers/helpers. Install ViGEmBus separately from the
[official v1.22.0 release](https://github.com/nefarius/ViGEmBus/releases/tag/v1.22.0)
if it is not already present; no driver installation is performed by this ZIP.

Validation: 498 automated regression tests passed; web, service and native builds
passed. Native tests verified real XInput held/neutral output and watchdog/rearm.
Six short hardware scenarios measured approximately 200 Hz Gamepad Hall with
p99 of 6–7.25 ms, approximately 60 LED FPS and zero Hall timeouts. A completed
303-second 6-key Pressure Wave run measured 199.999 Hz and Hall p99 of 6 ms.
Extended testing was canceled at the user's direction; no 30-minute or 2-hour
qualification result is claimed. Physical cable unplug/replug and Windows
sleep/wake remain unverified. See `docs/GAMEPAD_VALIDATION.md` for scope and results.

The Windows package includes Node and ViGEmClient licenses. Release assets include
the complete Windows ZIP and SHA256 checksum plus the signed core and update
manifest. A separate web deployment ZIP and its checksum are also included.
