# OpenHero68 RGB Service v0.3.2

Switching to Custom Effects after a long Rhythm session could block the service while its firmware simulator replayed time spent in Rhythm. The web then timed out and incorrectly reported that the app had stopped. Custom now starts with a fresh animation timeline; sleep/resume and delayed callbacks also have bounded catch-up work. Normal animation cadence and live edits retain their timing.

Compatible signed core updates now find the native helper in the installed app folder. API 5 and launcher 0.3.1 are retained; existing compatible launchers can install this core with Check for updates. A full Windows ZIP is also provided.

The web source includes the recent Rhythm session/preview fixes, transient connection recovery, repeating reactive preview samples, and Multicolor defaults for new Custom bases. Explicit saved Single black settings are preserved. Deploy the web build separately to Cloudflare Pages.

Validation: 467 automated tests passed, including transitions after three hours, repeated starts, normal 60 FPS cadence, and eight-hour resume simulation. Web and service builds passed. Physical audio-to-light latency and side rhythm support are unchanged; stock V3.20 still has no verified side-stream command.
