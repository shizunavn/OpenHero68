# OpenHero68 service v0.5.3.2 / UI v0.9.57

Remove audio Beat Pulse (Rhythm mode 430) because its beat detection was
unreliable on real music. Remove the detector, renderer and timing controls;
the proposed Speedcore controls are not included.

Saved Beat Pulse presets and web drafts migrate to Dynamic Spectrum (428),
retaining shared audio/color settings. New API and native requests for mode
430 are rejected. Other Rhythm modes and Custom Tempo Pulse (manual BPM)
retain their existing behavior.

Install the complete Windows setup and deploy UI 0.9.57 to remove this mode
from both the native app and web editor.

Validation: 585 JavaScript tests pass, including legacy preset migration and
rejection of new mode 430 commands. Native Rhythm regressions pass; the Windows
HID helper compiles and actual loopback capture still provides a PCM meter with
no stale state after stop. Web and service TypeScript builds pass, and the
Cloudflare Pages ZIP is verified. Browser fixture shows the seven remaining
Rhythm modes without Beat Pulse and no console errors.
