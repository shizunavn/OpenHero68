# OpenHero68 v0.4.3

Gamepad configuration now applies automatically. Start/Stop remains the main
control; there is no Apply configuration or Gamepad Save to profile button.
Rapid changes coalesce without overlapping requests. Editing a running profile
retains the existing Xbox controller; firmware remaps are rewritten only when
assigned keys or keyboard suppression settings change.

- Analog curve points move immediately while dragging. Local and service saves
  wait until release; interrupted gestures restore the previous curve.
- Digital buttons use the key's keyboard Actuation Point and Rapid Trigger.
  The 0.10–3.40 mm travel controls appear only for analog stick/trigger bindings.
- Mapping has a floating drag icon, destination preview and drop animation.
- Background Service has separate service, keyboard and ViGEmBus statuses,
  direct official driver download and clearer installation steps.
- Missing ViGEmBus still locks Gamepad. RGB does not require the driver.

Validation: 518 automated tests passed, web and service TypeScript builds passed,
native Hall/mapping checks passed, signed core and full Windows package verified.
Browser checks used a simulated service, without opening a physical keyboard or
installing a driver. Curve save timing was covered by queue regression tests;
pointer dragging was not automated by the available DOM-only browser backend.
No additional hardware benchmark or extended stress test was run.

The compatible signed core update requires launcher **0.4.2 or newer**. The full
Windows ZIP bundles launcher 0.4.3. ViGEmBus 1.22.0 remains a separate install.
The Cloudflare Pages ZIP contains the production web build and worker; uploading
it to Pages is separate from this GitHub release.
