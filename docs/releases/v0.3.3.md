# OpenHero68 RGB Service v0.3.3

Tachyon Mode uses 8000 Hz polling and turns off key and side lighting to minimize input latency. Custom Effects, Rhythm Sync and automatic Hall polling are paused while Tachyon Mode is enabled. The background app stays connected, and Hall Stream telemetry remains available.

Tachyon persists an exact snapshot of key and side lighting configurations (mode, brightness, and palette) before turning off LEDs, and restores them when Tachyon Mode is disabled. Lighting writes are guarded while Tachyon is active to prevent accidental mode switches.

The web source includes the dropdown menu layout fix, resolving asymmetric spacing and empty right gutters on short select menus.

Validation: 490 automated tests passed, including Tachyon snapshot capture, readback verification, error recovery, and lighting write guards. Web and service packages built and verified.
