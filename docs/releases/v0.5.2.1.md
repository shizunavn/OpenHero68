# OpenHero68 service v0.5.2.1

- Redesign Multicolor Scan with a continuously flowing spectrum, a soft light
  envelope and eased turns. Remove abrupt random color changes at scan boundaries.
  Color animation stays smooth independently of scan speed and skipped frames.
- Improve automatic Multicolor contrast over Aurora for Scan, Breath, Ripple,
  Reaction, Trail, Jelly, AOE, Touch and Pressure Wave. Choose from a hue range
  that contrasts with the entire animated background palette, including its
  intermediate colors and lower legacy Aurora/Comet layers.
- Keep event colors stable through presses, holds and fades. Comet retains its
  selected palette; using the same palette as Aurora can still reduce contrast.
- Support three- and four-part service versions in setup updates, installation
  records and Windows executable metadata. API version remains 6.

**Updating from v0.5.2 or earlier:** download and run
`OpenHero68-Setup-Windows-x64.exe` manually. Older updaters only recognize
three-part versions and cannot automatically install this four-part release.
The installer preserves saved settings.

Validation includes Multicolor Scan continuity at turns and spectrum boundaries,
Aurora contrast across automatic-color effects, render cadence independence,
encoded HID packet limits, version ordering and signed setup update handling.
GitHub Actions builds and tests the web app and Windows installer, runs isolated
installation/update/rollback smoke tests, and signs and verifies the release
assets before publishing. LED appearance has not been checked on a physical
keyboard.
