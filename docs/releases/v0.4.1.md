# Gamepad firmware blocking and smooth tester

Mapped keyboard keys can now use empty action `0x00000000` directly on HERO68,
with durable backups, exact remap restoration and recovery after service restart.
The Windows hook is an optional fallback, disabled by default in Configuration;
its anti-cheat warning is shown only when selected. Advanced Key conflicts are
rejected before writes. Keyboard binding icons match the controller palette.

Tester input is decoupled from 4 Hz diagnostics. A lightweight native stream
targets 60 Hz, with browser Gamepad API animation when the controller is
unambiguous. No additional Hall polling is introduced. Analog rate diagnostics
no longer show the 100 Hz digital rate as the analog rate.

Install the full Windows 0.4.1 package and the separately installed ViGEmBus
1.22.0 driver. Stop Gamepad and quit the old service before replacing its files.
Firmware suppression does not guarantee anti-cheat compatibility. Recovery
requires the original keyboard and USB port when firmware has no unique serial.
