# OpenHero68 service v0.5.1

- Fix: tray "Check for updates" no longer shows a blocking "Up to date" dialog
  before the Windows toast notification appears. All update results (up to date,
  updating, failed) now use consistent toast notifications; only the "package"
  case that requires user action keeps a dialog.
- Fix: tray "Check for updates" no longer shows "Updating the app" toast when
  the app is already up to date. The launcher now receives the real result
  only after the version check completes.
- Fix: Windows atomic file rename retries on EPERM/EBUSY to prevent rare
  crashes during concurrent status reads and writes on NTFS.
- CI: GitHub Actions actions updated to @v4 tags (Node.js 24 compatible).
